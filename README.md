# 🎶 My Lyrics Site

A sleek, dark-themed personal lyrics collection website built with a modern purple aesthetic, clean typography, and dedicated pages for your favorite tracks.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

---

## ✨ Features

- **Custom Dark & Purple Aesthetic:** Designed with a deep, immersive color palette (`#1a1c29` / `#12131c`) and subtle purple accents for a great nighttime reading experience.
- **Dedicated Song Pages:** Individual, beautifully styled pages for your curated song collection (7 tracks + homepage).
- **Unified Styling:** Consolidated CSS architecture (`style.css`) for consistent layout and typography across all pages.
- **Custom Favicon:** Features a music emoji (`🎶`) set against a matching purplish background.
- **Lightweight & Fast:** Built purely with vanilla HTML, CSS, and JavaScript—no heavy frameworks or bloat.

---

## 📂 Project Structure


my-lyrics-site/
├── index.html          # Homepage listing the song collection
├── style.css           # Consolidated global stylesheet
├── favicon.ico         # Custom site icon (purplish background with 🎶 emoji)
└── [song-pages].html   # Individual song lyrics pages

🚀 Getting Started

To run or view this project locally:

    Clone the repository:
    Bash:
    git clone [https://github.com/Breader67/my-lyrics-site.git](https://github.com/Breader67/my-lyrics-site.git)

    Navigate into the project directory:
    Bash
    cd my-lyrics-site

    Open the site:
    Double-click index.html or open it in your browser (or use a local development server like VS Code's Live Server).

🛠️ Tech Stack

    HTML5 for semantic document structure.

    CSS3 for custom styling, layout, and theme colors.
